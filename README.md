# PROJECT-WAR

SpaceWar é um jogo arcade espacial desenvolvido em JavaScript, HTML e CSS. Controle sua nave e enfrente ondas crescentes de asteroides e alienígenas, desvie de seus ataques, sobreviva o máximo possível e atinja a maior pontuação. Com sistema de níveis, pausa, efeitos visuais, sons de tiro e dano, HUD e fundo espacial personalizado.
